==================================================

Serveur : localhost

Utilisateur : dwh_user
Mot de passe : dwh_password

==================================================
ETAPES POUR CONFIGURER POWER BI DESKTOP
==================================================

1. Ouvrir Power BI Desktop

2. Cliquer : Obtenir les donnees

3. Chercher : PostgreSQL

4. Saisir les parametres :
   - Serveur : localhost
   - Base de donnees : datawarehouse
   
5. Cliquer : Connecter

6. Authentification :
   - Utilisateur : dwh_user
   - Mot de passe : dwh_password
   - Cliquer : Connecter

7. Selectionner les tables a charger :
   
   RECOMMANDE (Vues Analytics) :
   - analytics.v_patient_health_summary
   - analytics.v_health_metrics
   
   OU Tables Brutes :
   - staging.stg_patients
   - staging.stg_medical_tests
   - staging.stg_medications
   - staging.stg_appointments
   
   OU Tables Dimensionnelles :
   - dim.dim_patient
   - dim.dim_doctor
   - dim.dim_date
   
   OU Tables Factuelles :
   - fact.fact_medical_tests
   - fact.fact_appointments

8. Cliquer : Charger

9. Dans Power BI, creer les relations entre tables

10. Creer les visualisations et dashboards

==================================================
ASSISTANCE
==================================================

Si vous avez des problemes :
1. Verifier que PostgreSQL est en cours d'execution
   docker-compose -f docker-compose-dwh.yml ps
   
2. Tester la connexion au port 5432
   Test-NetConnection localhost -Port 5432
   
3. Verifier les identifiants
   User: dwh_user
   Password: dwh_password
   Database: datawarehouse
