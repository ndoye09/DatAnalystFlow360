## Mesures DAX à Créer

### Mesures Simples
- `Nombre Patients` = COUNTA(dim_patient[patient_key])
- `Nombre Tests` = COUNTA(fact_medical_tests[test_id])
- `Nombre RDV` = COUNTA(fact_appointments[appointment_id])

### Mesures Calculées
- `Cholestérol Moyen` = AVERAGE(fact_medical_tests[cholesterol])
- `Tension Systolique Moy` = AVERAGE(fact_medical_tests[systolic_bp])
- `Glucose Moyen` = AVERAGE(fact_medical_tests[glucose])

### Mesures de Pourcentage
- `% Cholestérol Élevé` = DIVIDE(COUNTIF(fact_medical_tests[cholesterol] > 240), COUNTA(fact_medical_tests[test_id])) * 100
- `% Tension Élevée` = DIVIDE(COUNTIF(fact_medical_tests[systolic_bp] > 140), COUNTA(fact_medical_tests[test_id])) * 100

## Dashboards Suggérés

### Dashboard 1 : Vue d'ensemble
- 4 KPIs (patients, tests, médicaments, RDV)
- 2 graphiques circulaires (genre, cholestérol)
- 1 graphique barres (âge)
- 1 tableau (top 10 patients)

### Dashboard 2 : Analyse Médicale
- Jauge cholestérol moyen
- Jauge tension systolique
- Graphique barres : types de tests
- Graphique ligne : évolution cholestérol

### Dashboard 3 : Suivi Rendez-vous
- Graphique barres : RDV par spécialité
- Jauge : taux complétude
- Tableau : RDV à venir
- Matrice : RDV par patient

### Dashboard 4 : Patients à Risque
- Tableau filtrable : patients risque
- Jauge : % population risque
- Graphique dispersé : cholestérol vs glucose
- Slicer : groupe d'âge

## Notes Importantes

### Performance
- Utiliser les vues `analytics.*` pour les dashboards
- Appliquer des filtres dans Power Query si possible
- Configurer l'actualisation en heures creuses

### Sécurité
- Ne pas partager les identifiants PostgreSQL
- Utiliser l'authentification Single Sign-On si possible
- Chiffrer les connexions si accès distant

### Maintenance
- Actualiser les données quotidiennement (02:00 UTC)
- Vérifier la intégrité des données mensuellement
- Archiver les anciens rapports trimestriellement
